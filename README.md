# 와우고 3D 교실 안내도

와우고등학교 교실 배치를 3D 로 돌려 보며 찾는 안내도입니다.

- 주소: https://trmoo.github.io/wawoohs-3d/
- **암호를 아는 사람만 열 수 있습니다.** 암호는 **교내 와이파이 비밀번호와 같습니다.**

이 저장소에는 암호로 잠근 안내도 파일(`index.html`) 하나만 들어 있습니다.
안내도 내용은 AES-256-GCM 으로 암호화되어 있고, 열쇠는 암호에서 PBKDF2(SHA-256, 60만 번)로 만듭니다.
파일 안에는 암호도, 암호의 해시도 들어 있지 않으며, 맞는 암호를 넣으면 브라우저 안에서만 풀립니다.
